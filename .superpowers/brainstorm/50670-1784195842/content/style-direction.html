A — 极简终端

深黑底色 + 单色青绿高亮（#2dd4bf）。极细线框，无渐变无阴影。JetBrains Mono 全局等宽字体。像 SpaceX 控制台 / VS Code 暗色终端的混合体。

关键词：克制、精密、命令行美学

B — 深紫星空

深空背景 + 蓝紫渐变 + 金色点缀。圆角卡片，柔和发光边框。字体混排（Inter 正文 + JetBrains Mono 数据）。像科幻飞船控制面板 + 暗色 Notion 的融合。

关键词：科技感、层次感、高级暗色

C — 绿色终端

纯黑底 + 单色荧光绿（#00ff00）。全面 CRT 终端风格，扫描线纹理。像老式大型机终端 / 黑客电影界面。字体统一等宽。

关键词：复古未来、命令行原生、极客风
