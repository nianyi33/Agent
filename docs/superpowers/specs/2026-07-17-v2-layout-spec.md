## 二、组件详细规范

### 2.1 顶部导航栏

- **通栏通透**设计，横跨全屏顶部
- 高度 48px，背景 `var(--bg-glass)` + `backdrop-filter:blur(12px)`
- 底部 0.5px 分割线

**左侧**：
- 系统名称 "TreeSloth AI OS"，字体 Inter 13px weight 600
- 版本号 Badge "v2.0"：紫色背景 `var(--primary)`，圆角 999px，padding 2px 8px，字号 9px

**中间**：
- Slogan："你的第二大脑 · 你的AI员工 · 你的数字伙伴"
- 字号 11px，颜色 `var(--text-muted)`，letter-spacing 0.5px
- 居中显示

**右侧**（从左到右）：
- 🔍 搜索图标按钮（36px 圆形）
- 🔔 通知图标按钮（带红色圆点 Badge）
- ⚙ 设置图标按钮
- 👤 用户头像（32px 圆形，紫色边框）

### 2.2 左侧菜单栏

- 宽度 **260px**，玻璃拟态背景
- 右侧有 0.5px 分割线

**Logo 区**（顶部）：
- 34px 圆角方形品牌图标（蓝紫渐变）
- 文字 "TreeSloth AI OS" + 版本号 Badge

**菜单项**（从上到下）：
- 🏠 Home — **选中态**：蓝紫渐变高亮背景，左侧 3px `var(--primary)` 竖线条
- 💼 Workspace
- 🤖 Agent Studio
- 🧠 Memory Universe
- 🔧 Tools
- ⚙ Settings

每个菜单项：padding 9px 12px，圆角 10px，font-size 13px weight 500。
默认：`color: var(--text-muted)`。Hover：文字变白，背景 `var(--card-hover)`。
选中：文字白色，背景 `linear-gradient(90deg, rgba(99,102,241,0.15), transparent)`，左侧紫色竖线。

**底部提示框**（侧栏底部，间距 margin-top: auto）：
- 气泡样式卡片，淡紫色背景 `rgba(99,102,241,0.08)`
- 文字："💡 提示：按住 **空格键** 可以快速呼出语音助手"
- 字号 11px，颜色 `var(--text-muted)`

### 2.3 中央核心展示区

占据屏幕中心最大面积。分为上下两部分：

**上半部 — 星际能量力场球**：
- 占据中央 2/3 宽度 × 约 400px 高度
- 这是语音球 Canvas（`#voice-canvas` 200×200）的容器
- 视觉特征：蓝色光耀线条、能量脉络、星环环绕、紫色星云背景
- 由 `voice-core.js` 的 Fibonacci 粒子球引擎渲染
- 下方有文字标签："按住说话 · 松开发送 · 或输入 / 命令"

**下半部 — 6 个核心能力卡片**：
- 2×3 Grid 或 6 列 grid，gap 12px
- 每个卡片 `glass-panel` 样式 + hover 上浮 2px

| 图标 | 标题 | 描述 |
|------|------|------|
| 💬 | 智能对话 | 深度思考与创作 |
| 💻 | 电脑控制 | 操作你的电脑 |
| 🧠 | 记忆系统 | 持续学习进化 |
| 🔗 | 工具调用 | 连接数字世界 |
| 🎤 | 语音交互 | 自然语音对话 |
| 🤖 | 创建Agent | 打造专属AI员工 |

### 2.4 右侧状态栏

宽度 240px，垂直排列两个卡：

**上方 — AI 状态卡片**：
- 标题 "AI 状态" + 右侧绿色圆点 "● 空闲中"（带 CSS `animate-pulse`）
- 主文本："你好！我已准备就绪，可以为你搜索、分析、创作和执行任何任务。"
- 底部：蓝紫渐变 SVG 波形图（或用 CSS animation 模拟）

**下方 — 今日任务卡片**：
- 标题 "今日任务" + "查看全部 →" 链接
- 三个任务项，每项 flex row：

| 图标 | 任务 | 时间 | 状态 |
|:--:|------|------|------|
| ✓(绿) | 整理文件夹 | 10:24 | 已完成 |
| ⟳(蓝) | 分析市场调研报告 | 11:03 | 执行中... |
| 🕐(灰) | 准备周会PPT | 14:00 | 等待执行 |

### 2.5 底部全局输入栏

横跨中部偏下区域，margin: 0 auto，max-width: 800px。

- **容器**：圆角 999px（胶囊形），玻璃面板，min-height 56px
- **左侧**：圆形蓝色麦克风按钮（42px，蓝紫渐变），click 触发 `voice-btn`
- **输入区**：textarea，placeholder "按住空格开始说话"
- **快捷标签**（输入框下方）：🔍 搜索 · 📄 分析 · 🎨 创作 · ⚙️ 执行 — pill 样式，bg-white/5，hover 变亮
- **右侧**：
  - 📎 附件回形针图标
  - 发送按钮（42px 圆形，紫色背景 `var(--primary)`，白色 → 图标）

## 三、配色 Token

| Token | 值 | 用途 |
|-------|-----|------|
| `--bg-base` | `#0B0F19` | 全局底盘 |

| `--border-glass` | `rgba(255,255,255,0.08)` | 玻璃面板描边 |
| `--border-glass-top` | `rgba(255,255,255,0.15)` | 玻璃面板顶部亮线 |
| `--primary` | `#6366F1` | 主靛蓝 |
| `--accent` | `#A855F7` | 辅紫色 |
| `--text-main` | `#F8FAFC` | 主文字 |
| `--text-muted` | `#94A3B8` | 次文字 |

## 四、实现约束

### 不改的

- 所有 JS 文件（`app.js`, `chat.js`, `voice-*.js`, `api.js`, `config.js`）
- 所有 HTML 元素 ID 和 class 名
- 后端代码
- 语音管道（阿里云 ASR+TTS）

### 改的

- `styles.css` — 按此规范重写 Token + 布局 + 组件 + 动效
- `app-shell.js` — 调整 HTML 生成结构以匹配新布局

### 回滚

```bash
cp build/original-backup-v2/* src/ui/brain-ui/
npm run build
```
