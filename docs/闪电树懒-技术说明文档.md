## 一、项目概述

**闪电树懒**是一款基于 Tauri 框架构建的本地优先桌面 AI 助手。它将大语言模型（LLM）对话能力、文件与命令执行代理、联网搜索、浏览器自动化以及 35 个领域专家技能打包为单文件 NSIS 安装包，用户下载即用，无需安装 Node.js 或 Python。

### 核心定位

- **本地优先**：所有用户数据（数据库、配置、沙箱文件）存储在 `%APPDATA%\闪电树懒\`，不上传云端
- **自带运行时的桌面应用**：内置 Node.js v24.14.0 运行时 + 完整 node_modules 依赖，零环境要求
- **多模型接入**：通过芯云 API 聚合平台一键接入 DeepSeek / GLM / Kimi / Qwen / MiniMax 等 17 个模型
- **Agent 技能系统**：35 个领域专家技能自动关键词匹配，覆盖创作、开发、产品、安全、销售等场景

## 五、Tauri Shell（Rust）启动流程

[lib.rs](desktop/src-tauri/src/lib.rs) 中的 `setup()` 钩子在窗口显示前自动执行：

```
1. resolve_backend_root()    → 查找 resource_dir/backend/
2. resolve_node()            → 查找 backend/node.exe
3. Kill 3721 端口占用        → netstat | taskkill
4. （若 node_modules 缺失）  → npm install --production (best-effort)
5. 注入环境变量              → BAILONGMA_PORT=3721
                              BAILONGMA_RESOURCES_DIR=backend/
                              BAILONGMA_USER_DIR=%APPDATA%\闪电树懒
6. .env 检查（非空才传）     → --env-file=.env (optional)
7. cmd.spawn("node","src/index.js") → 后台启动后端
8. 窗口销毁 → kill 后端      → WindowEvent::Destroyed
```

### 环境变量体系

| 变量 | 值 | 用途 |
|------|-----|------|
| `BAILONGMA_PORT` | `3721` | 后端监听端口 |
| `BAILONGMA_RESOURCES_DIR` | `<安装目录>/resources/backend/` | 只读资源目录 |
| `BAILONGMA_USER_DIR` | `%APPDATA%/闪电树懒/` | 可写用户数据目录 |

**关键修复**：`lib.rs` 注入 `BAILONGMA_USER_DIR`，将所有运行时写入（SQLite、config.json、sandbox、media）指向始终可写的 `%APPDATA%`。在此之前，打包后默认写入安装目录（Program Files 只读），导致数据库写入失败。

## 七、CORS 安全策略

后端 [api.js](src/api.js) 的前后链路安全由两套机制保证：

**Origin 白名单**（`isLoopbackOrigin`）

```
允许：127.0.0.1 / localhost / ::1 / tauri.localhost
```

`tauri.localhost` 是 Tauri v2 WebView2 的生产环境 Origin。开发时 Vite 使用 `localhost`，不受影响。

**敏感路径双重门控**（`requireLocalOrToken`）

对所有管理操作额外验证 TCP 连接来源必须在 `127.0.0.1` 上——即使 Origin 被伪造，远程 CSRF 仍被网络层拦截。

**关键修复**：此前 `tauri.localhost` 未在白名单，导致前端所有请求报 403 `forbidden origin`。添加后 CORS 通路完全打通。
